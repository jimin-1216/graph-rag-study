# Ranking Rules v1

작성일: 2026-04-24

## 목적

질문 의도와 주체를 함께 고려해서 검색 결과를 재정렬하기 위한 1차 랭킹 규칙이다.

## 기본 원칙

최종 점수는 아래 네 축의 합으로 본다.

```text
final_score
= base_keyword_score
+ subject_match_score
+ intent_positive_score
- intent_negative_score
- wrong_subject_penalty
```

## 1. 주체 일치 가중치

같은 `일치`라도 강도를 나눈다.

### 강한 일치

- 제목에 주체가 직접 들어 있음
- 본문 첫 문장 또는 초반에 주체가 직접 등장

예:

- `제7조 (보고책임자)`
- `보고책임자는 ... 하여야 한다`

### 약한 일치

- 본문 중간에 한두 번 언급됨
- 다른 주체 조문 안에서 부수적으로 등장함

예:

- `이사회는 ... 보고책임자 등에게 ...`

### 점수 방향

- `subject_in_title`: 크게 가산
- `subject_in_lead`: 크게 가산
- `subject_in_text`: 반복 등장 수만큼 제한적으로 가산

## 2. 의도별 긍정 신호

### 역할/책임 질의

가산 신호:

- 제목에 `역할`, `책임`, `업무`, `총괄`, `보고책임자`
- 본문에 `역할 및 책임`, `책임은 다음 각 호와 같다`
- `총괄한다`, `수행한다`, `보조한다`, `하여야 한다`
- 각 호/각 목 열거 구조

### 기한/시기 질의

가산 신호:

- `이내`, `영업일`, `즉시`, `지체 없이`, `신속하게`, `적시에`
- 제목에 `보고시기`, `기한`, `방법`

### 절차 질의

가산 신호:

- 제목에 `절차`, `방법`, `제도운용`
- 본문에 `다음 각 호와 같다`
- 단계형 열거 구조

## 3. 의도 충돌 감점

질문 의도와 어긋나는 조문은 감점한다.

### 역할/책임 질의에서 감점

- 제목이 `자료의 보존`
- 제목이 `시행일`
- 제목이 `부칙`
- 제목이 `보고시기 및 방법`
- 제목이 `보고내용`

또는 본문에서

- 기한성 표현만 반복됨
- 보존/기록/서식 중심 문장만 나타남

### 기한/시기 질의에서 감점

- `보존대상`
- `자료의 보존`
- `보고내용`
- `서식`

## 4. 주체 불일치 감점

의도는 맞아도 주체가 틀리면 감점한다.

예:

- 질문 주체: `보고책임자`
- 후보 조문 제목: `이사회`, `은행장`, `감사`

이 경우 `역할 및 책임`이라는 표현이 있어도 질문의 직접 답이 아닐 가능성이 크다.

따라서:

- 제목에 다른 주체가 있으면 감점
- 본문 초반 주어가 다른 주체면 감점

## 5. 예시

### 좋은 후보

`제7조 (보고책임자)`

- 제목 정확 일치
- 본문 초반에 `보고책임자`
- `역할 및 책임은 다음 각 호와 같다`
- 각 호 열거

=> 높은 점수

### 나쁜 후보

`제27조 (자료의 보존)`

- 본문에 `보고책임자`는 있지만
- 제목이 `보존`
- 역할 정의가 아니라 특정 보존 책임만 설명

=> 감점 필요

### 경계 후보

`제5조 (은행장)`

- 역할/책임 조문이긴 함
- 그러나 질문 주체는 `보고책임자`가 아님

=> 완전 제외는 아니지만 감점해서 뒤로 보내야 함

## 현재 구현 방향

1. 주체 일치를 `제목 / 본문 초반 / 본문 전체`로 분리한다.
2. 역할 질의에서는 `다른 주체 조문`에 감점을 준다.
3. 의도 충돌 제목을 명시적으로 감점한다.
4. 결과 리포트에 feature를 같이 출력해서 왜 순서가 바뀌었는지 설명 가능하게 유지한다.
