# 260423 Plan

## 목표

- 법령 alias 문제를 개별 예외처리가 아니라 정규화 파이프라인으로 다룬다.
- 내부문서의 `REFERS_TO_LAW_NAME`를 실제 `LegalDocument` 후보에 자동 해소한다.
- 자동 해소 결과와 미해소 결과를 분리해 이후 Graph RAG 품질 개선의 기반으로 쓴다.

## 작업 순서

1. alias 해소 파이프라인 요구사항을 문서화한다.
2. 본문 내 `이하` 약칭 패턴을 추출하는 규칙을 만든다.
3. 법령명 문자열 정규화 함수를 만든다.
4. 후보 문서 생성과 점수화 로직을 만든다.
5. `resolved / unresolved / alias_catalog` 산출물을 저장한다.
6. 샘플 결과를 검토하고 어디서 실패하는지 분류한다.

## 원칙

- 수동 사전은 fallback으로만 쓴다.
- 자동 해소가 애매하면 억지로 연결하지 않는다.
- 결과물은 Neo4j 반영 전 파일로 먼저 검수한다.
- 규칙은 특정 케이스가 아니라 반복되는 표현 패턴에 맞춘다.
